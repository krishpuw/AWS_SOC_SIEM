    Threat hunting is proactively searching raw data based on an educated guess to find hidden attacks that automated alerts missed.

        Proactive: You actively seek out threats rather than waiting for alarms to go off.

        Hypothesis-driven: You start with a specific theory of what an attacker might be doing.

        Deep Dive: You analyze raw logs to uncover malicious activity that slipped past automated defenses.

    Incident Response:- is reactive - waiting for an alert to fire 


SIEM catches an attack- 
        Reconnaissance — port scans, service enumeration. Your rule: distinct_ports > 10 from one IP. MITRE T1046.
        Initial Access — brute force, phishing link clicked, exploited public-facing app. Your rules: failed login count, SQLi string in web log. MITRE T1110, T1190.
        Execution — malicious script runs, PowerShell downloads payload. Detected via endpoint logs (process creation events, command line arguments). MITRE T1059.
        Persistence — attacker creates a backdoor user, adds a scheduled task, installs a service. Detected via Windows Event 4720 (new account created), 4698 (scheduled task). MITRE T1136, T1053.
        Privilege Escalation — attacker moves from standard user to admin. Detected via Event 4672 (special privileges assigned), 4728 (user added to privileged group). MITRE T1068.
        Lateral Movement — attacker pivots from compromised host to other internal systems. Detected via unusual internal RDP/SMB connections, pass-the-hash patterns. MITRE T1021.
        Exfiltration — large data transfer out, unusual destination, data staged in archive files. Detected via threshold rules on outbound bytes, DNS tunneling patterns. MITRE T1048.
